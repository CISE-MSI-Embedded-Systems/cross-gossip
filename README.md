## Run Simulation

```
cd ./simulation/build
cmake ..
make
./simulation <pick_different_node_id_s>
```

## Run Tester Sketch 

1. Set this repo as your sketchbook

2. Go to `Tester.ino` and change `NODE_ID` each time (not ideal, works for now)

3. Then click upload

4. Repeat steps 2 through 3 for other devices
